# Implementation Plan

## Slice 0 — Foundation
Next.js, TypeScript strict, Tailwind, env validation, database, health endpoint, lint/typecheck/test.

## Slice 1 — Auth
Login/logout, secure session, role Admin/Head/Teacher, server authorization.

## Slice 2 — Data Dasar
Pengguna, pengajar, santri, wali sebagai kontak, periode, master surah.

## Slice 3 — Halaqah
CRUD halaqah, assignment pengajar, membership santri, pindah halaqah, access control.

## Slice 4 — Hafalan
Form mobile-first, Sabaq/Sabqi/Manzil, kelancaran, validasi ayat, riwayat, duplikasi.

## Slice 5 — Koreksi dan Audit
Batas 24 jam, alasan, before/after, void tanpa hard delete.

## Slice 6 — Dashboard
Ringkasan, filter periode/halaqah, santri perlu perhatian, aktivitas terbaru.

## Slice 7 — Laporan PDF
Pilih santri/periode, pratinjau, PDF, download/print, metadata.

## Slice 8 — Pilot
Seed data, mobile test, authorization test, backup/restore, deployment, panduan pengguna.
